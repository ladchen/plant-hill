# 植物山 PLANT HILL 双产品长图档案

静态产品展示页，无构建步骤、无外部字体和前端依赖，可直接部署到 GitHub Pages。

## 当前结构

首页：[index.html](index.html)

顶部固定产品导航只保留两款产品：

- `01` 人参组培不定根固体饮料
- `02` 人参组培不定根鹿肾丸

点击任一产品后，页面只显示该产品的完整内容，不会把两款产品连续铺在同一个长页面中。

## 每个产品包含

1. 独立首屏和品牌标题。
2. 直接进入完整产品长图，长图前不重复增加产品图片区或引导文案。
3. 阅读器支持章节定位、阅读进度、放大、缩小与桌面拖动。
4. 该产品对应的 PDF 检测报告。

## 亚健康状态自测

- 入口位于首屏“阅读完整长图”右侧。
- 6 道题覆盖精力、专注、睡眠、作息、体力恢复和剂型偏好。
- 结果会给出 RG2、鹿肾丸或双产品组合的信息匹配建议。
- 自测仅用于日常状态参考与产品信息选择，不构成医学诊断、治疗建议或功效承诺。

## 成分气泡融合

- 使用用户提供的本地组件 `products/plant-hill/成分气泡融合组件.html`。
- 组件已复制到 `interaction/成分气泡融合组件.html`，直接内嵌在产品首屏与完整长图之间。
- RG2 产品区域显示 5 个配方气泡；鹿肾丸产品区域显示 14 个原料气泡。
- 嵌入模式隐藏组件内部产品标签，避免与网页顶部产品导航重复。
- 支持点击气泡融入产品核心、粒子爆发、全组方融合提示和重新开始。
- iframe 高度根据组件内容自动扩展，桌面与手机端均无内部横向滚动。

## 长图方式

- RG2 原图 `790×20789`，拆为 `10395px + 10394px` 两段加载，页面内同宽、零间距无缝拼接。
- 鹿肾丸原图 `790×11874`，完整单图展示。
- 长图直接作为页面主体，原文案、版式和图片不重新制作。

## 本地预览

在本目录运行：

```bash
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

## 内容边界

- 全部产品素材来自用户提供的压缩包。
- 页面明确两款产品均属于食品，不能替代药品。
- 当前没有虚构价格、购买链接、销量或额外功效承诺。
- `directions.html`、`preview-*.html` 和 `showcase-prototype.html` 为设计过程保留，不属于当前版本。
